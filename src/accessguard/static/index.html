Who has access they should not?

AccessGuard checks whether any one person holds a combination of permissions that should be split between people, such as being able to both create and approve a payment.

Running the demo? Use the admin token from your terminal, for example admin-token-demo.

How to read this page

Each organisation defines pairs of permissions that one person should not hold together. A finding is a person who holds both halves of a pair, sometimes through two different roles. Findings are rated by how much harm the combination could do. A manager can accept a finding with a written reason, which is recorded, or fix it by removing a role. Every change is written to a log that detects tampering.
